# Prompt - Create User Trip Structure

Using JSON, generate a sample trip itinerary that I can use to prototype a shared trip itinerary application.

The itinerary should include
- a name and a cover photo
- it should include 5 days
- there should be 4 travellers in the group on the trip
- each traverller should have first name, last naae, avatar photo and preferred experience type
- experience types are like: food, sports, adventure, party, health, relax, culture, sights
- for each day in the intinerary, include a list of events
- an event is an experience at a location
- each experience could be generic like "walking around the eiffel tower" or more specific like "NHL Oilers playing the Florida Panthers @ 8PM at Amerant Bank Arena, Sunrise Florida on Jan 10th, 2026"
- each event should have a photo from unsplash
- each location would be geographic - a municipality, state, country
- the order of events in the intinerary matters.  Use date/time of the event if available - but order should be maintained independently to allow for changes
- use unsplash-mcp for any photos


Ask questions about events, experiences, locations as required
