## 2026-09-19
Alice here. `localhost` only works on the Mac itself, so the iPhone needs your Mac's address on your home Wi-Fi.

**On the real iPhone (same Wi-Fi as the Mac)**
1. Stop the current server with Ctrl-C, then restart it open to your local network:
   ```
   python -m http.server -d dist 8000 --bind 0.0.0.0
   ```
   If macOS asks whether Python can accept incoming connections, click **Allow**.
2. On the iPhone, open Safari and go to **http://<mac-ip>:8000/<slug>/**
3. Press Ctrl-C when you're done. While it runs, anyone on your Wi-Fi can open the page.

If it doesn't load, check that both devices are on the same network and that the Mac's firewall isn't blocking Python. Also, `<mac-ip>` can change after a reboot; `ipconfig getifaddr en0` gives the current one.

**Quick look without the phone**
- **Safari on the Mac:** Develop › Enter Responsive Design Mode, then pick an iPhone. If the Develop menu is hidden, turn on Safari › Settings › Advanced › "Show features for web developers".
- **Chrome:** open DevTools with Cmd-Opt-I, turn on the device toolbar with Cmd-Shift-M, then pick an iPhone.

The real phone is worth doing once: it's the only way to check touch, especially whether dragging moves the map or scrolls the page. Quincy couldn't test that.
